# Limites connues — version 1.0

- Application locale mono-utilisateur ; aucun accès réseau n'est validé.
- Les collectes dépendent de la disponibilité et des formats des services
  publics INSEE, INPI, BODACC et Annuaire des entreprises.
- La comparaison PDF extrait le texte localement mais n'effectue pas d'OCR ; un
  PDF scanné est signalé comme non exploitable.
- Les règles et comparaisons automatiques ne constituent pas une analyse ni un
  conseil juridique.
- Les échéances estimées et internes sont distinguées des dates officielles.
- Le HTML reste le format de référence des rapports programmés.
- L'écriture par API est désactivée dans cette version.
